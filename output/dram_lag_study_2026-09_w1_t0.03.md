# DRAM 株急騰 → 日本の装置・材料・基板株の伝播タイミング実測

作成: 2026-09-14 ／ スクリプト: `scripts/_tmp_dram_lag_study.py`（標準ライブラリのみ）

## 主要結論（数値は下の表から・解釈は仮説）

1. **遅れて上がる「伝播ラグ」は観測できない。反応は同日〜翌日で終わる。** 相互相関のピークは全層で lag=0（A +0.33・B +0.19・C +0.18）、lag=1 が次点（MU の終値が日本の引け後に付くため翌営業日に持ち越される分）、lag≥2 はほぼ 0。
2. **イベント当日〜翌日の超過リターンは装置が最大、材料は小さい。** h=1 平均: A +2.8%（勝率 73%）／B +1.1%（62%）／C +1.4%（59%）。材料層は h=10 まで勝率 50% 前後＝コイン投げと区別できない。
3. **h=20〜60 の超過は上がるが（A +13.5%・C +11.4%・B +6.6%）、これは「遅れて反応」ではなく DRAM 上昇局面が続いた時の同方向トレンド（サイクル継続＋β>1）の反映。** 期間で割ると、装置 A は 2024 年以前も h=60 中央値 +4.5%（2025〜 +7.1%）と安定だが、**材料 B・基板 C の h=40〜60 の上乗せは 2025 年以降のイベントだけ**（B h=60 中央値: 〜2024 +0.2% → 2025〜 +6.3%／C: −0.6% → +24.7%）で、2024 年以前は 0 と区別できない。勝率は 55〜62% 止まり。

## 前提・式

- **DRAM バスケット**: MU（USD）・SK hynix 000660.KS（KRW）・Samsung 005930.KS（KRW）の日次リターン等加重。各社の現地通貨建て Yahoo adjclose（分割補正済み）。営業日は3社の和集合、欠損日は前日終値を繰り越し（その日のリターン=0）。
  - MU: 20160912〜20260911・2514日
  - 000660.KS: 20160919〜20260914・2446日
  - 005930.KS: 20160919〜20260914・2446日
- **イベント**: バスケット指数の 1 営業日リターン（level[t]/level[t-1]-1）が初めて +3% を超えた日。超え続ける間は新規にせず、一度 +3% を割り、かつ前イベントから 5 営業日以上あいた後にだけ次を採る。
- **反応**: t0 = イベント日以降で最初の日本営業日（TOPIX がある日）。基準= t0 の前営業日終値。超過リターン(h) = [close(t0+h)/close(t0-1) − 1] − [TOPIX(t0+h)/TOPIX(t0-1) − 1]（%）。h=0 は t0 当日の反応を含む。日本株の終値は AdjFactor 累積で分割補正（bars の AdjC は使わない）。
- **勝率** = 超過リターン > 0 の割合。n = (イベント × 銘柄) の観測数（両端の終値がある組だけ）。
- **相互相関**: 日本株の日次超過リターン（対 TOPIX）と DRAM バスケットの日次対数リターン（日本営業日に集約: 前営業日〜当日の海外営業日分の和）の Pearson 相関。lag>0 = 日本株が DRAM に遅れる（DRAM の lag 日前のリターンと当日の日本株）。層は銘柄の相関を単純平均。

## 限界

- 標本数: イベント 109 件（2016-09〜2026-09 の約10年）。層別 n はイベント数 × 銘柄数で、同じイベントの銘柄同士は独立でない（実質の自由度はイベント数）。
- DRAM サイクル: この期間に含まれる上昇局面は 2016-17・2020-21・2023-24・2025-26 の4回程度で、イベントの多くは同一局面内の連続検知。
- 為替を無視: DRAM 3社は現地通貨建て、日本株は円建て。円安局面では日本株側の超過リターンが為替要因で膨らむ。
- イベント定義の恣意性: 10営業日 +10% ／ 間隔 20 営業日は事前に決めた値だが最適化はしていない。閾値を変えれば件数と結果は変わる。
- 超過リターンは TOPIX 単純差（β=1 仮定）。装置株は β>1 なので上昇相場では超過が過大に出る。
- 相互相関は日次で 0.05〜0.15 程度の小さい値になるのが普通で、ピーク lag の差は統計的に区別できない可能性が高い（n≈2400 日で ±0.04 が 95% 帯の目安）。
- lag=1 の相関は MU の終値が日本の引け後（米国時間）に付くことで生じる持ち越し分が主で、翌営業日の「遅れた反応」ではなく同日反応の時差。

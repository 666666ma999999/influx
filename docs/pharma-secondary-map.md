## 0. なぜ既存の受益マップが使えないか（本ファイルの存在理由）

既存 `configs/x_shortage_map.json` は「**品薄 → 価格上昇 → 作り手が儲かる**」の対応表で、
7つの型（price / capex / demand / secondary / resale / disruption / broad）を持つ。
医薬の薬価はこのどれにも当てはまらない:

- 薬価は**国が決める公定価格**で、改定＝**強制的な値下げ**（市場の需給で上がることがない）
- したがってXで「薬価改定」の波を検知しても、それは**逆風の波**である。既存の受益表の当て方
  （品薄→その品目を作る会社を買う）をそのまま適用すると、**符号を誤って逆風銘柄を買う**
- 実測の裏づけ: `data/center_pin/center_pin.jsonl` は既に医薬9社＋卸2社に
  pin=「薬価（引き下げ構造）」sign=**+** を付与済み（＝薬価が下がると株価にマイナス）。
  該当: 科研製薬4521 / 小野薬品4528 / 参天製薬4536 / キッセイ4547 / 東和薬品4553 /
  ゼリア新薬4559 / 杏林製薬4569 / サワイGHD4887 / アルフレッサHD2784 / スズケン9987 ほか

**新設する型**: `regulated_price_cut`（制度による強制値下げ）。
- `actionable: false`（**この型は単体では銘柄を出さない**）
- 銘柄を出してよいのは、下記の**二次波及の連鎖が実測で確認できた場合のみ**

## 1. 二次波及の3連鎖（候補・裏取り前）

### 連鎖A: シェア集中（薬価引下げ → 不採算品の限定出荷 → 供給余力のある大手へ需要シフト）

```
薬価引下げ ─→ 後発品の採算悪化 ─→ 不採算品の限定出荷・供給停止 ─→ 処方が残存メーカーへ
                                    （X観測点: e2 厚労省供給状況bot・限定出荷）
```
- 候補: サワイGHD(4887) / 東和薬品(4553)
- **この連鎖の急所**: 同じ会社が薬価引下げの直撃も受ける。**数量増のプラスと薬価減のマイナスの
  どちらが大きいか**が実測で分からなければ、符号が決まらない＝銘柄を出せない
- X観測点は e1（薬価改定）ではなく **e2（限定出荷・供給停止の個別品目公表）** の方が近い
  （§16s で e2 は件数10の保留・品目複合での再試験が前提）

### 連鎖B: 薬価差の維持（中間年改定の見送り・緩和 → 卸・調剤の採算改善）

```
中間年改定の見送り観測 ─→ 薬価差益が残る ─→ 医薬品卸・調剤薬局の採算改善
     （X観測点: e1の陳情投稿＝厚労省宛「中間年改定はやめてほしい」の波）
```
- 候補: アルフレッサHD(2784) / スズケン(9987)（いずれも台帳 pin=薬価(引き下げ改定)）
- **この連鎖の急所**: 政策の見送りは**単発イベント**になりやすく、§16i境界3（単月スパイク＝
  地政学・政策イベントは買ってはいけない）に抵触する疑い。持続的な波になるかは未検証
- 実測の傍証（要裏取り）: 4-6月期に調剤関連が軒並み営業損失（アルフレッサ▲4.98億・
  スズケン▲2.29億・カメイ▲1.46億・バイタルKSK▲0.60億・ほくたけHD▲0.71億／出所=X投稿の実数、
  一次資料での確認が関門C）

### 連鎖C: 個別品目の収載・適応拡大（受益は品目依存企業）

```
薬価収載・適応拡大の公表 ─→ 対象品目の売上増 ─→ 品目依存度の高い企業
     （X観測点: 業界紙AnswersNewsの週次まとめ・m4は汎用語のため品目複合が必須）
```
- 候補: 台帳で pin_type=event の企業（アステラス4503=特許切れと新薬承認 /
  第一三共4568=エンハーツの適応拡大・承認 / エーザイ4523=レケンビ投与患者数 など）
- **この連鎖の急所**: 単一品目の営業利益寄与度は**開示されないことが多い**。
  §16a関門Bの「営業利益構成比≥30%」が確認できなければ却下（無理に立てない）

## 2. 関門（既存規律の医薬版・すべて通過が条件）

- **関門A（型）**: `regulated_price_cut` は actionable=false。連鎖A/B/Cのいずれかが成立した時のみ
  その連鎖の受益側を候補にする
- **関門B（実在）**: 銘柄コードは `data/center_pin/center_pin.jsonl`（TOP1000台帳・977社）に
  実在するもののみ（上記候補はすべて実在を確認済み）
- **関門C（決算裏取り・ユーザー恒久指示 2026-07-28）**: 営業利益セグメント構成比を実読し
  ≥30%=確証 / 10-30%=候補 / <10%・符号逆=却下。**連鎖Aは「数量増と薬価減の差引き」が
  会社の開示で確認できることを追加条件**とする
- **関門D（波形）**: §16i境界1-4。単発の政策イベント・スパイクは見送り、複数週の持続的増加のみ

## 3. 現時点の結論（裏取り前・暫定）

- 型 `regulated_price_cut` を新設し、**e1（薬価改定）は観測専用**として運用する
  （銘柄を出さない＝§16a disruption と同じ扱い）
- 3連鎖のうち**実装に最も近いのは連鎖A**（X観測点 e2 が個別品目の公表botで一次情報・
  持続型）。ただし符号決定に関門Cの追加条件が要る
- 連鎖Bは§16i境界3（政策イベント）に抵触する疑いが濃く、**優先度は低い**
- 連鎖Cは開示の壁で却下される可能性が高い（関門Cで自然に落ちる設計）

### 連鎖ごとの結論

- **連鎖A（シェア集中）= 買えない**。サワイ・東和の4文書を「他社／競合／需要シフト／シェア獲得／代替需要」
  で全文検索して**該当ゼロ**。両社が説明する数量増の要因は薬価改定と別（選定療養制度・自社増設）。
  さらに薬価影響額を金額分離していないため、**マイナスとプラスの大小比較が原理的に不能**
- **連鎖B（薬価差の維持）= 買えない・前提が実測で逆**。2026年4月改定は**見送られず実施済み**。
  両社とも流通改善ガイドラインに沿って薬価差を**縮める**側に立つと宣言。「調剤▲4.98億」は裏取れたが
  **赤字拡大**であって受益ではない
- **連鎖C（新薬・適応拡大）= 判定不能**。単一セグメントで製品別営業利益の開示なし（売上依存度は高い）。
  恒久ルール（営業利益ベース）では判定できず、無理に立てない

### 統括による訂正（レビュアーの指摘1件を棄却）

裏取り担当は「台帳 `center_pin.jsonl` の 2784/9987/4553/4887 が sign=+ なのは実測と矛盾＝要修正」と
報告したが、これは**sign の定義の誤読**。正本 `docs/price-watch-universe.md:120` は
**「sign: センターピン上昇時の利益方向」**と定義しており、pin=薬価・sign=+ は
「薬価が上がれば利益プラス＝**下がればマイナス**」という正しい記載である。**台帳は修正しない**。
（むしろこの sign=+ は、薬価が構造的に下がる一方である以上、当該11社にとって薬価が**逆風**であることを
台帳が既に正しく記録していた証拠）

## 5. 最終裁定（2026-08-09）

**医薬レーンの e1（薬価改定・中間年改定・薬価収載）は恒久的に「観測専用」とする**（銘柄を出さない）。
根拠4点（すべて実測）:
1. **受益者が実在しない** — 実読6社すべてが薬価引下げを一律にマイナスとして説明。プラス側の会社ゼロ
2. **タイミングが情報にならない** — 薬価改定は毎年4月1日告示の**日付が事前確定した既知イベント**。
   Xに波が立つ時点で新情報でない（§16i境界2「常時話題の語は使えない」の制度版）
3. **伝達経路が観測できない** — 卸は年度後半まで価格が未妥結（スズケンで9割弱が見積り計上）。
   改定シグナルから四半期利益への経路が確認できない
4. **単発イベント型** — §16i境界3（政策・地政学の単月スパイクは買ってはいけない）に該当

型 `regulated_price_cut` は `configs/x_shortage_map.json` に**追加しない**（受益側が空で
`actionable_rule`「TOP1000内に受益銘柄が居なければ非対象」により自動的に非対象になるため、
空の型を足すのは器の増殖にしかならない）。本ファイルが「なぜ足さないか」の記録として正本になる。

**再訪条件**: ①後発品大手が「他社の供給停止による自社への需要シフト」を決算で**明記**した時
②薬価改定の営業利益影響額が金額分離で開示された時 ③連鎖Aの観測点 e2（限定出荷の個別品目公表）が
品目複合で入場試験を通過し、かつ①が揃った時。

# Batch2「本当にX外か」監査 結果（第17R事前登録・第18Rでゲート格上げ／2026-07-25 実施）

> 記述分析・**台帳不算入**。目的＝「急騰271銘柄のうち手元コーパスで事前言及が見つからなかった244銘柄」が
> **X上に本当に存在しないのか、それとも我々の収集網が漏らしただけか**を層化標本で判定し、
> 発掘レーン継続の可否ゲートにする。

## 方法
- 母集団: 未捕捉244銘柄（急騰271 − 事前言及あり27）。
- 抽出: 四半期 × 業種17 × 規模3分位（前月ユニバースrankの3分位）で層化・**24銘柄**（seed=20260725）。
- 実行: 各銘柄の**急騰前の窓**（search_window_from〜to）で X 検索（社名優先・社名不明はコード）。
  収集は cookie ベース（maaaki）・浅いスクロール4・間隔30秒。件数と本文サンプル3件を記録。
- 分類: 件数だけでは判定不可（コード検索は電話番号等の無関係投稿を拾う実証あり）のため、**本文を読んで人＋AIで分類**。

### 実物の証拠（事前コール）
- **4586 メドレックス**（急騰開始 2025-09-09・+55.8%）: 窓内に「**最強の日本株リスト(低位株) ① メドレックス（4586）

- **7746 岡本硝子**（急騰開始・+41%）: 窓内に「**【岡本硝子(7746)チャート分析】…投げ売り一巡感あり。短期的には自律反発の余地**」
  および「**④岡本硝子（7746）現在株価315円 ⇒ 短期目標株価435円超え**」＝分析＋目標株価。

## 判定（事前宣言に対する結論）
事前登録の分岐宣言は「**本当にXにない%が≧70% → 発掘打ち止め(c)／収集漏れ主因 → 既存収集の穴埋め**」。

- 「**Xにない**」と断定できた銘柄は **0件**（C の7件もサンプル3件では"無い"証明にならない＝証拠は非対称。
  "在る"は1件で証明できるが "無い"は全数走査が要る）。
- 逆に「**X上に投稿は在る**」は 14/21 で実証、うち 2件は**明確な事前コール**。
- ⇒ **「90%はX外」説は棄却**。未捕捉244の主因は **我々の収集網が57アカウントに限られていること（収集漏れ）**。

**ゲート結論: 発掘レーンは "打ち止め(c)" ではなく "既存収集の穴埋め"。** ただし後述の理由で
「未知アカ全域クロールの新規構築」には進まない。

## 同時に判明したコスト・制約（実測）
- **X側ブロック 3/24（13%）**: 30秒間隔・浅いスクロールでも発生。無差別に検索量を増やすとアカウント保護が破綻する
  （第18R B10「分母と成功確率」の実データ）。
- 1銘柄あたり所要 ≈ 1.5分（4スクロール＋間隔30秒）。244銘柄全数なら ≈ 6時間＋ブロックリスク。
- コード検索は無関係投稿を大量に拾う（5727 の例: パチンコ店告知・ポルトガル語投稿）。**社名検索が必須**。

## 次の一手への含意（第18Rの配分に反映すべき点）
1. 発掘の天井は「X外」ではないが、**捕まえられるのは"銘柄リスト系・チャート分析系"の投稿者**であり、
   fxnia級（中立EVが生き残る）とは限らない。**存在証明 ≠ 収益性の証明**。
2. 穴埋めの方向は「全域クロール構築」ではなく、**この監査で実際に見つかった発信者を起点に少数を中立採点**する
   （安く・既存の採点器で処理でき、打切り基準も既にある）。
3. C の7件は「無い」証明ではないため、**"X外率"という指標を今後使わない**（第18R B9 採択）。

## 2. 公開時刻と取得遅延（PIT の核心）

### 一次情報URL
- 立会時間: https://www.jpx.co.jp/equities/trading/domestic/01.html （2024/11/04更新）
- J-Quants `/v2/td/list` 仕様: https://jpx-jquants.com/ja/spec/td-list
- J-Quants 更新タイミング: https://jpx-jquants.com/ja/spec/data-update

### 取得できた事実
- **時刻粒度は「分」まで（秒はない）**。無料一覧の「時刻」列は `HH:MM`、J-Quants の `DiscTime` も仕様上 **`開示時刻（HH:MM）`**。第三者APIの `pubdate` も秒は常に `00`（サンプル32,625件すべて）。
- 立会時間（2024-11-05以降の現行）: 前場 **9:00–11:30** / 後場 **12:30–15:30**、注文受付は 8:00〜 / 12:05〜。
- **開示時刻の分布（実測・サンプル32,625件＝2025年の2月・5月・8月・11月の全開示）**

| 時間帯 | 件数 | 比率 |
|---|---:|---:|
| 〜08:00未満 | 5 | 0.0% |
| 08:00–08:59（寄り前） | 423 | 1.3% |
| 09:00–11:29（前場ザラ場） | 1,520 | 4.7% |
| 11:30–12:29（昼休み） | 1,494 | 4.6% |
| 12:30–15:24（後場ザラ場） | 5,160 | 15.8% |
| 15:25–15:29（クロージングオークション） | 4 | 0.0% |
| **15:30–15:59（引け直後）** | **13,940** | **42.7%** |
| **16:00以降** | **10,079** | **30.9%** |

  → **引け後（15:30以降）が 73.6%**。当日ザラ場中に出るのは **20.5%**。
- **イベント種別ごとの引け後比率（同サンプル）**: TOB/公開買付 84.6%（n=305）・資本業務提携 83.2%（n=196）・MBO/非公開化 82.3%（n=79）・業績予想の修正 75.4%（n=1,250）・希望退職 92.9%（n=14）・自己株式の取得 64.7%（n=2,207）。**カタリスト系ほど引け後に寄る**。
- **「知った時刻→次に約定できる時刻」は機械的に決められる**（分粒度で十分）。運用ルール案:

| 開示時刻 t | 次に約定可能な時刻（保守側） |
|---|---|
| t < 08:00 | 当日 09:00 寄り |
| 08:00 ≤ t < 09:00 | 当日 09:00 寄り（注文受付中＝板寄せに参加可） |
| 09:00 ≤ t < 11:30 | 当日ザラ場（同分の約定は取らず **t+1分以降**。より保守的には当日引け） |
| 11:30 ≤ t < 12:30 | 当日 12:30 後場寄り |
| 12:30 ≤ t < 15:30 | 当日ザラ場（同上） |
| **t ≥ 15:30** | **翌営業日 09:00 寄り** ← 全開示の 73.6%、TOBは 84.6% がここ |

- **配信遅延**: J-Quants アドオンは「開示情報が発生次第、順次反映。**反映までに時間を要する場合があります**」（公式 data-update）。JPX公式Qiita解説では「TDnetで公開されてからおおむね**数分〜数十分（混雑時は1時間程度）**の遅延」。
  → **翌寄りエントリー設計（=73.6%の母集団）には遅延は無影響。当日ザラ場執行を狙う設計には不適**。

### 未確認
- 「引け後」の中でも 15:30ちょうどに 42.7% が集中する理由（15:30–16:00に大量）。**推測:** 引け直後に開示を寄せる実務慣行。本報告の結論には影響しない。

## 5. 代替経路（無料・安価）

### 5-1. 第三者インデックスAPI「TDnet WEB-API（非公式）by やのしん」← **最重要**
- 一次情報URL: https://webapi.yanoshin.jp/ ・ https://webapi.yanoshin.jp/llms.txt ・ https://webapi.yanoshin.jp/robots.txt
- 事実:
  - `GET https://webapi.yanoshin.jp/webapi/tdnet/list/{YYYYMMDD-YYYYMMDD}.json?limit=N` で**日付範囲の全開示インデックス**を取得可能（銘柄コード指定・XBRL絞り込みも可）。認証不要・無料。
  - 返却項目: `pubdate`（**YYYY-MM-DD HH:MM:SS**、秒は常に00＝実質分粒度）/ `company_code` / `company_name` / `title` / `document_url`（TDnet本体へのリダイレクトリンク）/ `markets_string` / `update_history` / XBRL各種URL。
  - **遡及: 2009-10-10 の開示まで取得できた**（2009-06は0件）。＝**約16年9ヶ月分**。
  - **完全性の検証（本調査で実施）**: 公式TDnet一覧の「全NNN件」と件数が完全一致。2026-07-21=212/212、07-22=214/214、07-23=183/183、07-24=410/410。
  - robots.txt は `User-Agent: * / Allow: /`（Googlebotのみ形式別に制限）。加えて **AIエージェント向けの `llms.txt` を自ら公開**＝機械アクセスを想定した設計。
  - 制約: **非公式サービス**（可用性・継続性の保証なし）。`document_url` は TDnet本体を指すため**31日超の本文PDFは403で取得不可**（＝インデックスのみ生き残る）。1リクエストの上限は実測で週次チャンク（~1,000件）は安定、月次一括（~8,000件）は HTTP 500。
- **未確認**: 明示的な利用規約ページ・商用利用条項・レートリミットの公式値（サイトの「ご注意」は「インターネットを利用した情報収集、分析を目的としたもの」「書類データは提供元サイトを必ず確認」の記載のみ）。

### 5-2. 既存の自前収集器との重複判定
`scripts/edinet_fetch.py` と `scripts/jq_fetch.py` を精読した結果:

| 必要な情報 | 既存経路で代替できるか | 判定 |
|---|---|---|
| 大量保有報告書・変更報告書 | `scripts/edinet_fetch.py`（docTypeCode 350/360、2021-07-07〜、日次launchd稼働中） | **完全に代替済。TDnet不要** |
| 公開買付届出書・自己株券買付状況報告書・有価証券届出書 | `edinet_fetch.py --dataset documents_all`（全書類一覧を無加工保存、2021-07-07〜） | **書類ベースでは代替済**。ただし**TDnetの適時開示（「〜に関するお知らせ」）はEDINET提出より先に出る**ため、**イベント検知時刻はTDnetの方が早い**（既に `docs/stock-algo-kpi-catalog.md:2518` で時刻精度限界として明記済） |
| 決算短信（PEAD・進捗率） | `jq_fetch.py --only fins`（`/v2/fins/summary`） | **代替済** |
| 決算発表予定日 | `jq_fetch.py --only earnings_calendar` | **代替済**（前向き専用） |
| 業績予想の修正 | J-Quants財務の修正履歴で部分復元可。**「修正率」の正確な算出には短信/開示本文が要る** | **部分代替** |
| 自社株買い「決議」の日時・取得上限株数 | EDINETの自己株券買付状況報告書は**月次・事後**。決議当日は取れない | **TDnet固有**（表題＝Yanoshinで無料、上限株数＝本文が必要） |
| 資本業務提携・分割・MSワラント・立会外分売・優待・希望退職 | EDINET/J-Quantsに該当データセットなし | **TDnet固有**（表題＝Yanoshinで無料） |
| 配当予想の修正 | J-Quants「配当金データ」は **Premium(¥16,500/月)** のみ | Standard では未取得。表題レベルはYanoshinで無料 |

**結論（重複判定）**: TDnetアドオンが**唯一もたらす追加価値は「開示本文（PDF/XBRL）の数値」**。表題・銘柄・分単位時刻というインデックス層は Yanoshin で無料・16年分・完全性検証済のため、**アドオンの5年遡及インデックス（`/td/bulk`）は無料経路と機能的に重複する**。

## 6. 今日から無料で始める価値がある作業

### 消失リスクの層別判定（EDINET/日証金の実害との比較）
| 層 | 無料での後付け取得 | 永久欠損リスク |
|---|---|---|
| **インデックス（表題・コード・分単位時刻）** | **可能（Yanoshin・2009-10〜、公式と件数完全一致）** | **なし**（前向き収集を今日始めなくても失わない） |
| **開示本文（PDF・XBRL）** | 不可（TDnet本体は31日で403、有料アドオンは5年ローリング） | **あり。契約が1年遅れるごとに最古の1年分が永久に買えなくなる** |

→ **EDINET/日証金と同種の「今日から始めないと永久欠損」は、本文層にのみ存在する。ただし本文は無料では前向き収集しても規約リスク（robots.txt 全面 Disallow）があるため、"今日から無料で本文を貯める" は推奨しない。**

### 推奨する最小アクション（優先順）
1. **【今日・1回・無料】Yanoshin から全史インデックスを一括アーカイブする**
   - 設計: `scripts/tdnet_index_fetch.py`（新規、`jq_fetch.py` と同流儀＝冪等・週次チャンク・gzip保存・`fetch_log.jsonl`）→ `data/tdnet/index/YYYYMMDD.json.gz`（週次ファイル or 日次分割）。
   - 規模の**算出**: 年間約97,900件（§3実測）× 16.8年 ≒ **164万件**。1件約350バイト（実測JSONから）→ 生JSON約 **570MB**、gzip後は**推定 80〜120MB**。リクエスト数 = 16.8年 × 52週 ≒ **874回**（週次チャンク）。0.5秒間隔で **約15分**。（前提: 週次チャンクなら1リクエスト約1,000件で安定＝本調査で実測。確度: 概算）
   - これで着手可能になるKPI: `stock-algo-kpi-catalog.md` の #12 自社株買い（決議日時のみ）・#14 資本業務提携・#15 公募増資/売出し（負けフィルタ）・#16 MSワラント・株式分割・立会外分売・株主優待・BL-1 TOB先回り。**すべて「表題マッチ＋開示時刻」だけで v0 検証が回る設計になっている**。
2. **【今日・無料】日次の前向き差分取得を既存 launchd に1本追加**（同スクリプトの `--recent` モード）。理由は消失対策ではなく、**実運用のPIT整合（当日の開示を当日中に取り込む導線）を先に作っておくため**。
3. **【契約しない】TDnet本体（release.tdnet.info）への自動巡回はしない**。robots.txt が全面 Disallow。本調査での取得は仕様確認目的の少数手動アクセスに留めた。

## 7. コスト対効果

**前提（明示）**
- 現在の月額: **J-Quants Standard ¥3,300/月**（出所: `docs/stock-algo-kpi-catalog.md:265`）。
- アドオン: **¥11,000/月（税込）**（出所: JPXプレスリリース・一次確認）。
- 年間イベント件数: §3の実測サンプル年換算（出所: 本調査の実測・確度=概算）。

**算出**
- 年額増分 = 11,000 × 12 = **¥132,000/年**。月額総額は 3,300 → **14,300円/月（+333%）**。
- 「本文が要るイベント」だけを分母にした単価:
  - 業績予想の修正（修正率の算出に本文が必要）: 132,000 ÷ 3,750件 = **¥35/件**
  - 自己株式の取得（取得上限株数比率に本文が必要）: 132,000 ÷ 6,600件 = **¥20/件**
  - TOB関連: 132,000 ÷ 915件 = **¥144/件**
  - 希望退職・人員削減: 132,000 ÷ 42件 = **¥3,143/件** ← **「AI人員削減」仮説単独では費用対効果が成立しない**
- **一方、インデックスのみで足りる場合の単価は ¥0/件**（Yanoshin・§5-1）。

**判断**
- **アドオンの価値＝「本文の数値」に限定される**。表題マッチで v0 が回るKPI群（#14/#15/#16/分割/立会外分売/優待/TOB先回り）は **¥0 で今日から検証開始できる**。
- したがって **¥132,000/年は「表題だけでは判定できない強度指標（修正率○%以上・取得上限○%以上）が実際にリフトを生む」と実測できるまでは支払う根拠がない**。
- **ただし遅延の代償は明確**: 契約を1年遅らせると2021年分の本文が永久に取得不能になる。**5年遡及が必要な検証を計画に入れるなら、その検証に着手する時点で即契約**（後追いは不可能）。

# 業界予測記事の日に「利益の柱が一致する受益株」を買うと勝てるか — TrendForce 全発表の遡り（P-INF-46 a・事前登録）

## 答える問い

オーナー原文: 「今の需要があり、不足しているものたちを調べて、過去の歴史から、次に何が不足するかを予測して、先に株価の先取りをしたいです。」
→ 本 task の下位問い: **「次に足りなくなる（値上がりする）」と業界予測が出た日に、その物が利益の柱の日本株を買うと、TOPIX に勝てるか（後知恵なし・外れた予測も含む）。**

## 対象と数え方

- **母集団（後知恵なし）**: TrendForce プレスセンター一覧（`https://www.trendforce.com/presscenter/news?page=N`）の**全発表**のうち、公開日 2016-07-05〜2026-09-30 で、題名が下表の品目語に当たり、かつ題名に方向語（上げ/下げ）がある物。**題名だけで機械判定**（本文で選び直さない＝結果を見て選ばない）。品目語に当たり方向語が無い物は件数だけ報告。
- 方向語（大文字小文字無視）: UP= rise / rising / increase / up / hike / climb / surge / jump / rebound / tight / shortage / undersupply / short supply / higher ／ DOWN= fall / falling / decline / drop / down / slide / plunge / oversupply / surplus / weaken / lower / correction。両方に当たる題名は「混在」で除外し件数報告。否定（no / not / end of）が方向語の直前 3 語にある物も混在扱い。
- 品目 → 受益株（`data/center_pin/center_pin.jsonl` の pin がその品目そのもの・sign を符号に使う）:

| 品目（題名の語） | 受益株（sign） |
|---|---|
| NAND / SSD | 285A キオクシア（+・2024-12-18 上場以降のみ） |
| DRAM / HBM | 6871 日本マイクロニクス（+）・6753 シャープ（−＝原価側・符号反転） |
| MLCC / passive components | 6981 村田製作所（+）・6976 太陽誘電（+）・4078 堺化学（+） |
| wafer / silicon wafer | 3436 SUMCO（+）・3445 RS テクノロジーズ（+） |
| substrate / ABF / IC substrate | 4062 イビデン（+）・4971 メック（+）・5706 三井金属（+・極薄銅箔） |
| panel / LCD（TV・monitor panel） | 6737 EIZO（−・符号反転）・5214 日本電気硝子（+） |

- **単位= 発表 1 本（イベント）**。同じ品目の発表が 5 営業日以内に続いた物は最初の 1 本に束ねる。イベントの値= 受益株の超過リターンの平均（sign − は符号反転）。
- **採点式**（`docs/stock-algo-kpi-catalog.md` §0 と同じ）: 入口= 公開日の翌営業日始値・超過= 銘柄騰落率 − TOPIX 騰落率（同期間）・窓 +20／+60 営業日。分割は `scripts/jq_fetch.split_rel_scale`。pre60（入口の 60 営業日前からの超過）も併記。
- **件数突合**: 〈一覧の取得ページ数／発表総数〉〈品目語ヒット数／方向あり／混在・方向なし〉〈束ねた後のイベント数／日足で採点できた数〉を報告に書く。

## 成功基準（事前登録・結果を見る前に commit）

主指標= **UP イベントの +60 営業日の超過**。合格= 次の 3 つを全部満たす。
1. UP イベントが 20 以上あり、+60 の勝率（超過 > 0）≥ 60% かつ中央値 ≥ +3pt。
2. UP イベントの +60 中央値 − DOWN イベントの +60 中央値 ≥ +5pt（同じ銘柄群での比較＝銘柄選択の後知恵を消す）。
3. 偽薬（同じ銘柄・同じ品目で、入口を 2016-10〜2026-07 の無作為な営業日に置いた 500 回）の +60 中央値の分布で、実際の UP 中央値が 90 パーセンタイル以上。
- 副指標（判定に使わない）: +20 の同じ 3 項目・品目別の内訳・pre60 で「もう上がっていた」かの分布。
- 不合格なら「業界予測の題名で買う型」は使わない。

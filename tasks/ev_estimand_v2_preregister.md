## 目的

凍結EVの「点推定=全シグナルプール平均」と「CI=月ブロック・ブートストラップ」が別の量を指す内部不整合を是正し、
目標文言（§0付記II「超過EVの片側95%下限>0」）が要求する統計量を凍結メタデータとして持てるようにする。
**これは推定量の定義変更であり、新しい仮説検定ではない（α非消費）。**

## 変更内容（凍結案）

1. **EV点推定 v2 = two-stage（月等ウェイト）**: 各暦月内のシグナル平均を先に取り、その月平均のグランド平均を EV とする。
   発火集中月（実測: guidance_fy_strong は1ヶ月で105/683=15%集中）への過重を除く。
2. **EV CI = 片側95%下限を正**: 既存 `bootstrap_ev_ci`（kpi_event_study.py:464・月ブロック）で **片側95%下限** を算出し凍結。
   両側95%は参考併記のみ。n_boot=2000・seed=42 固定。
3. **スキーマ追記（watchlist in_sample）**: `ev_<exit>_v2` / `ev_<exit>_ci1s_low` / `months_spanned` / `n_boot` / `seed` /
   `estimand_version: "v2"` を追加。**旧 `ev_*`（v1）は削除・改名せず保持**（方法版の分離。B2レビュー承認済みの作法）。
4. **適用範囲**: 改定後の**新規試行・新規陣入り判定から**適用。過去の陣入り・凍結済み verdict への遡及適用は禁止
   （定義変更で過去の合否を書き換えない）。
5. **欠測の扱い**: returns.csv が存在しない系統（実測: sue_x_above200・volshock_x_above200_quiet の2本）は
   v2 値を「未算出」と明示表示する。**欠測を0や旧値で黙って埋めない**（A側クロスレビュー指摘の欠測バイアス回避）。
6. **開示義務**: 実装時に v1→v2 の全19系統比較表を1回生成して本ファイルに追記（順位変動の透明化。判定には不使用）。

## 禁止（凍結）

- v2 算出後の n_boot / seed / 月定義 / 片側水準の変更（変えるなら v3 として再事前登録）
- v2 値を見てからの適用範囲・欠測規則の変更
- 本改定を理由とした過去 verdict の再裁定

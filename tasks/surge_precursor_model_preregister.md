## 0. 前提の正直な開示（読む前に必ず）

1. **発見データはholdout期間の内側**。発見窓 2025-07〜2026-06 は §6プロトコル1の holdout（2023-01以降）
   に完全に含まれる。よって**本特徴量群について holdout は既に汚染済み**（§7-AC の historical OOS と
   同型）。`holdout の残り資格` は本モデルの信任に使えない → **信任経路は前向きデータのみ**。
2. **目標イベントの定義差**。記述分析のケース定義は **+30%/20営業日**（`surge_episodes_1y.csv`）だが、
   §0のゴールは **+20%/20営業日「終値」**。本モデルの合否判定は**§0のゴール定義に統一**する
   （+30%到達率は副次診断としてのみ併記）。
3. **ブリーフの用語訂正**: `max20` は「直近20日高値からの伸び」ではなく
   **「反応日を含まない直前20営業日の日次リターン最大値」**（`scripts/kpi_pead_signals.py:128`
   compute_max20 の docstring）。ケース平均 0.0958 = 最大単日リターン9.6%の意。以後この定義で扱う。
4. **§8-6 原則に照らした本モデルの事前確率は低い**（§2-3 で詳述）。本書は「有望だから登録する」のでは
   なく「**規律ある形で1本だけ賭けて、安く早く殺せるようにする**」ための文書である。

## 1. モデル定義（1本だけ・凍結対象）

### 1-1. 名称と論理式

- `kpi_name` = **`surge_precursor_v1`**
- シグナル判定日 **D**（終値時点で全条件確定）／エントリー **D+1営業日 寄付**／出口 **20営業日後 終値**

```
signal(code, D) :=
      ( dev200(code, D)  >= 0.2774 )
  AND ( max20(code, D)   >= 0.0721 )
  AND ( membership_new(code, month(D)) == True )
  AND ( code in universe_TOP500(prev_month(D)) )
  AND ( 直近20営業日以内に同一codeの本KPIエントリーが無い )   # クールダウン（§4-2）
```

### 1-2. 使用特徴量（3つのみ・新規実装なし）

## 2. 機序（なぜこの3つか）と §8-6 原則A/B に照らした正直な評価

### 2-1. 各条件の機序

- **`dev200 >= 0.2774`（200日線を+27.7%以上上回る）** — in-sampleでEV+に触れた既存構成
  （champion系・SUE系）の共通項は「下方を有界化する成分」であり、その中核が **200日線上**。
  機序: 長期の平均取得単価を上回る位置＝含み損の投げが構造的に薄い＝**左裾（−20%級の崩落）の確率が
  母集団より低い**。原則B（左裾有界化と機序の必須記載）に対する本モデルの唯一の答えがこれ。
- **`max20 >= 0.0721`（直前20営業日に最大+7.2%の単日上昇）** — 機序: 「**点火は起きたが本噴火はまだ**」
  の状態。完全な無風銘柄が20営業日で+20%に届く経路は薄く、一方すでに連続ストップ高の銘柄は
  墓場②。その中間帯を1条件で切り出す。※これは純チャート＝原則Aの割引対象（§2-3）。
- **`membership_new == True`（当月TOP500への新規流入）** — 機序: 直近21営業日の売買代金で
  ユニバースに新規参入した＝**資金フローの体制変化**が既に起きている。かつ本条件は本記述分析とは
  **独立に実測されたアンカー**を持つ: §6ベースレート計測で
  **新規流入銘柄 P(+20%/20bd) = 6.9% vs 既存 3.5%（約2倍・両ユニバース定義で頑健）**。
  ＝ この1条件だけは「今回の426件から発見した相関」ではなく既存確定値である。

### 2-2. 制度イベント framing の有無（原則A/B の観点・正直に）

**本モデルに制度イベント framing は無い**。決算・開示・規制・指数入替などの触媒を1つも含まない
（`fins_within_20bd` の odds 0.93 が「急騰は決算と無関係」を示したため、入れるべき触媒が
記述分析からは見つからなかった）。§7-AH の実証どおり「制度イベント framing は必要だが十分ではない」
が、本モデルは**その必要条件すら満たしていない**。

### 2-3. 事前確率の自己評価（低い）

- 3条件のうち **2つ（dev200・max20）は純・価格/MA/チャート型** → **原則A の大幅割引対象**。
  墓場①の実測（GC 0.71 / range_breakout 0.12 / ma200_reclaim 0.95 / resid系 0.72-0.76 …
  すべて lift<1）に構造的に隣接する。
- **左裾有界化の成分は `dev200` 1本のみ**。champion（200日線上 **×静穏ベース**）より弱い。
  しかも「静穏」は本記述分析で d+0.02＝無効と実測されており、**championの左裾成分を丸ごとは
  継承できていない**。
- `membership_new` は 6.9%/3.5% の実測アンカーを持つ一方、§6手順5 が明記するとおり TOP500入替は
  「直前に出来高と株価が噴いた銘柄」を毎月流入させる仕組み＝**墓場②（注目後追い）と地続き**。
- 結論（**推測**）: 本モデルが正式合格に到達する事前確率は **10%未満**と見る（前提: 112試行で
  正式合格0本・墓場①②が12系統以上で再現・本モデルは触媒ゼロ。確度=定性判断・**根拠数字は
  「112試行0合格」のみで、10%という値そのものはAI仮置き**）。
- **それでも登録する理由**: (a) `membership_new` の 2倍アンカーが独立に存在する、(b) 3条件AND
  という極小の設計で追加実装コストがほぼゼロ、(c) 早く安く殺せる打切り条項（§6）を持てる、
  (d) 供給側は「候補ファクトリー/急騰前兆」に絞ると既に裁定済み。

### 3-1. 決定ルール（単一・グリッド探索なし）

**「発見期間のケース群の中央値（50パーセンタイル）を、そのまま絶対値の閾値として固定する」** —
これが唯一の閾値決定ルールである。感度50%（急騰銘柄の半数が超える水準）を設計で保証する意図。

| 特徴量 | 閾値 | 出所（一次） |

| `max20` | **0.0721** | 同上 |
| `membership_new` | **True**（二値・閾値なし） | 同上（比率特徴量） |

### 3-2. 禁止条項（凍結後は例外なし）

- **複数閾値の探索・比較を禁止**（グリッドサーチ・±の近傍再投入・分位点の刻み変更すべて）。
- **前向きでの分位点再推定を禁止**。上記の**絶対値をそのまま**適用する（ローリング分位にすると
  仕様が時間とともに動き、事前登録の意味が消える）。
- **レジーム別・時価総額別・業種別の閾値切替を禁止**。
- **結果を見た後の閾値変更・条件追加・条件削除を禁止**（前向き成績を見た変更は全て新規trial）。
- **派生モデルはすべて別trial扱い**（2条件版・`ret_60bd` 追加版・OR版・閾値違い版）。
  §8-6「既存familyの救済案生成禁止（近傍再投入）」により、**本モデルが fail した場合の近傍派生の

## 4. 分母の定義と評価指標（条件付き比較の禁止）

### 4-1. 分母（共通・凍結）

**分母 = 全銘柄 × 全営業日 の「銘柄日」**。具体的には
`各東証営業日 D における 前月末TOP500ユニバース in_universe 銘柄の全件`。

- **測るのは P(急騰 | 特徴) であり、P(特徴 | 急騰) ではない。**
  記述分析（本モデルの設計元）は後者の形式であり、**そのまま検定に使うことを禁止**する。
- **急騰銘柄426件だけを見た条件付き比較を合否判定に使うことを禁止**（分母不在のEVは測れない、の
  影響者発掘レーンと同じ誤り）。
- 4段階報告（signal / TOP500 / entry / confirmed）は §6付記II 17項の既存凍結どおり。

### 4-2. クラスタ・重複ウィンドウの扱い

- **同一銘柄のクールダウン**: エントリー成立後20営業日は同一銘柄の再発火を不算入（重複ウィンドウの
  系列相関の抑制。§6プロトコル5の趣旨）。
- **CIは月次ブロック・ブートストラップ**（既定 n_boot=1000。極端分位を要する感度確認時のみ
  `kpi_bonferroni_check.py` 準拠で n_boot=10000）。独立二項CIは使わない。

### 4-3. 主指標と対照ベースレート（**重要**）

| 指標 | 定義 | 対照 |
|---|---|---|
| **precision（到達率）** | 発火銘柄日のうち「D+1寄付→20営業日後終値が+20%以上」の割合 | — |
| **lift（主）** | precision ÷ **同期間・同月の `membership_new==True` 銘柄日の到達率** | **6.9%**（§6実測値。前向き期間で再計測した実値を使う） |
| lift（副） | precision ÷ 同期間・同月の全銘柄日の到達率 | 4.1%（全期間実測・参考） |
| **EV（主）** | EV(E1: SMA200割れ翌朝手仕舞い)・往復コスト0.3%込 | §0-4 更新どおり |
| EV（副） | EV(なし)・EV(-8%損切り) | 併記のみ |
| 副次診断 | +30%到達率 / 高値タッチ+20% / MAE / 中央値 / 集中度 | 合否に使わない |

> **なぜ主対照が 4.1% でなく 6.9% か**: 本モデルは `membership_new` を**必須条件**にしている。
> 全体ベースレート4.1%を分母にすると、§6で既に確定済みの「新規流入は約2倍」という**既知の効果を
> 本モデルの新発見として二重計上**してしまう。**本モデルが問われるのは「新規流入銘柄の中で
> dev200×max20 が上乗せを生むか」**であり、対照は 6.9% でなければならない。

## 5. PIT・holdout・シグナル頻度

### 5-1. PIT厳守（§6「横断的なPIT実装ルール」準拠）

- `dev200` / `max20`: シグナル判定日 **D の終値**までの情報のみ（両Canonical関数とも look-ahead
  回避が docstring で明示済み）。エントリーは **D+1寄付**。
- `membership_new`: 前月末までの21営業日売買代金で構築されるため、**当月の月初第1営業日以降**に
  確定。→ **critical_date = 各暦月の月初第1営業日**（§6付記II 7項の生成規則に本KPI行を追加）。
  月初第1営業日の欠測は**窓失効**（許容外）。
- ストップ高で D+1 寄付が約定不能な場合は §6手順6 の繰延ルール。期中上場廃止は最終取引日終値決済、
  TOB廃止は公開買付価格決済、権利落ち跨ぎは配当加算（§6手順2）。
- 実行証跡は `data/monitoring/run_log.jsonl`（§6付記II A節）。本KPIの依存関係表エントリ
  （入力=daily_quotes・universes_w21・必要as-of・取得締切・異常条件）をスクリプト定数で凍結する。

### 5-2. holdout・過去データの扱い（不可侵条項）

| 期間 | 扱い |
|---|---|
| 2023-01〜2026-06（holdout / historical OOS） | **開封禁止**。§0-1 のとおり本特徴量群については既に汚染済み。§7-AC 一括棄却スクリーンへの追加投入も**禁止**（同一データで発見した構成の再検定＝curve-fit） |
| 2016-01〜2022-12（in-sample） | **リターン非開封**。許可するのは「**シグナル件数の計数と実装正しさの確認のみ**」（＝アウトカム盲検）。ret/EV/liftの算出を禁止 |
| 前向き（登録日以降） | **唯一の信任経路**。§6付記II の正式判定プロトコルを適用 |

> 検討して**採らなかった案**: 「2016-2022でEVを見て、悪ければ登録しない」という事前宣言型の
> 拒否ルール。これは 2016-2022 を選抜段に格上げし、前向きαの意味を濁す（かつ同期間は既に112試行で
> 観察済み＝独立でない）。**リターン非開封の方が安く・正直**。

### 5-3. シグナル発火頻度の見積り

**算出**（登録前に実測で置き換える。以下は登録可否の見当をつけるための概算）:

```
分母  = 500銘柄 × 245営業日/年 ÷ 12 ≒ 10,208 銘柄日/月
頻度  ≒ 10,208 × P(dev200≥0.2774) × P(max20≥0.0721) × P(membership_new)
      ≒ 10,208 × 0.15 × 0.20 × 0.129 ≒ 39.5 銘柄日/月
```

**前提**（値とその出所）:
- 245営業日/年 … **AI仮置き**（東証の年間営業日概算）
- `P(membership_new)=0.129` … **実測**（precondition_report.md の ctrl率 12.9%）
- `P(dev200≥0.2774)=0.15` … **推測**（対照の中央値0.1039・平均0.1480の右裾分布から上位15%程度と見た）
- `P(max20≥0.0721)=0.20` … **推測**（対照の中央値0.0398・平均0.0554から上位20%程度と見た）
- 3条件の**独立性を仮定**。実際は正相関のため joint は上振れ側（推測: 40〜80/月）。逆に§4-2の
  20営業日クールダウンで3〜5割減（推測: 実効 20〜40/月）。

**確度 = 概算**。**結論を変える前提**: 実測頻度が月5.6件を下回ると §6付記III B-1 で
**スナイパー枠**（同時観察上限2・人的資源は自動運転のみ・概算最早判定日の印字必須）に落ち、
合否ラインも枠F→枠Sへ切り替わる（§6-1 の分岐）。

**キャリブレーション手順（1回のみ・アウトカム盲検・凍結前に実施）**:
1. 2016-2022 と 2025-07〜2026-06 の両方で**シグナル件数のみ**を計数（リターンは触らない）。
2. §6付記III B-3 の保守側算定（0件月も分布に含め、**中央値と平均の小さい方**）で予測頻度を確定。
3. 得られた頻度で **A級(≥8.0) / B級(5.6-8.0) / スナイパー枠(<5.6)** を機械分類し、本書に印字して凍結。
4. **この計数を見て閾値・条件を変更することは禁止**（頻度が想定外でもモデルは動かさない。
   動くのは「どの枠で登録するか」だけ）。

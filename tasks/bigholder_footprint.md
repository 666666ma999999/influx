# Task-light: 大口が入る前の「足跡」を過去の5%届出から逆算する（P-INF-16 候補・2026-09-13 オーナー裁定 a）

## Goal
「大口がこれから入りそうか」を先回りで示す銘柄別の物差しが無い（既存は届出後の計測のみ）。過去の新規大量保有報告（5%超・一般報告）の届出日 T の**前**に、出来高・売買代金・信用残・株価の動きに共通の型があるかを測り、あれば指数の候補を出す。

## 成功基準
- [ ] S1 事前定義（下記・凍結）どおりに 2021-07〜2026-09 の新規5%届出イベント（特例報告を除く・銘柄解決済み）と対照（同銘柄の無作為日・同数以上）で、T−60〜T−1 の特徴量6本の分布を比較し、事象/対照の中央値・上位25%・「閾値超えの割合」を表にする
- [ ] S2 期間を前半（2021-07〜2024-06）と後半（2024-07〜2026-09）に分け、前半で選んだ閾値が後半でも同じ向きに出るかを示す（後知恵の検査）
- [ ] S3 足跡が出た日（届出前に閾値を超えた日）を entry にした場合の 20/60営業日の超過リターン（銘柄−TOPIX）を、足跡なし日と比べて表にする（＝指数として使えるかの答え）
- [ ] S4 結果を `output/bigholder_footprint.md` に置く（実測メモ・欠測・注意つき）

## 凍結定義
- イベント: data/edinet/*.json.gz（2021-07-01〜）の ordinanceCode=060・formCode=010000（一般報告・新規の大量保有報告書）。同一 filer×issuer の初回のみ。issuerEdinetCode→証券コードは data/edinet/edinet_code_master.csv（前例 `_tmp_bigholder_precursor.py` と同じ）。特例報告（010001 等）は除外。
- T= 提出日。5%到達は T の約5営業日前（法定期限）なので、足跡の窓は **T−60〜T−6 営業日**（到達前）と **T−5〜T−1**（到達後・届出前）を分けて測る。
- 特徴量（すべて T−1 以前の情報のみ）: ①売買代金の比 = 直近20日平均 ÷ その前120日平均 ②同 5日/120日 ③出来高の最大日/120日中央値 ④信用買残の変化率（margin 週次 LongVol の 4週前比）⑤信用倍率（LongVol/ShrtVol）の水準 ⑥株価の超過リターン T−60→T−1（対TOPIX）。
- 対照: 各イベント銘柄につき、イベント T の ±120営業日を避けた無作為日を3日（seed=7）。
- 判定: 各特徴量で「事象の中央値が対照の上位25%を超えるか」と、閾値（対照の上位25%点）超えの割合（事象 vs 対照）＝ lift。
- S3 の entry: 前半期間で lift が最大の特徴量1本（または2本の AND）で閾値超えの日を全銘柄・全期間で拾い、20/60営業日の超過リターンを対照（閾値未満の日の無作為抽出・同数）と比べる。

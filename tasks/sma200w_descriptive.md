# 記述測定: 200週移動平均（≈4年線）乖離帯の +20%到達率 — 測定前凍結

起点: 2026-08-15 @AlphaOwlTrading スレッド（マンガー帰属の「クオリティ株は200週線で買え」・米株8銘柄列挙・
末尾は作図ツール Intrinsiqq の販促）。ユーザー裁定「測る」（2026-08-15）。

## 位置づけ（重要）

**記述測定のみ**＝ `output/tdnet/event_profile.md` と同じ扱い。**α非消費・trials.jsonl 不算入・
screening_batches.jsonl 不算入・verdict を持たない**。ここで良い数字が出ても合格ではなく、
事前登録（§7-*）へ進めるかの材料。閾値探索・条件の後付け最適化は禁止。

## 凍結仕様（測定前に固定・測定後の変更禁止）

1. **母集団**: TOP500（既存KPIと同一ユニバース・`measure_base_rate.build_universe` 系の月次メンバーシップを再利用）
2. **200週SMA**: 週足終値（各週の最終営業日の **AdjC**）の200週単純移動平均。履歴が200週に満たない
   銘柄×時点は対象外（充填・短縮での代用は禁止）
3. **サンプリング**: 各**月末営業日**に、その時点のTOP500全銘柄について乖離率
   `dev = AdjC / SMA200W - 1` を算出（月次＝重複窓を避ける。日次サンプリングはしない）
4. **乖離帯（凍結・8バンド）**: `< -20%` / `[-20,-10)` / `[-10,-5)` / `[-5,0)` / `[0,+5)` /
   `[+5,+10)` / `[+10,+20)` / `>= +20%`
5. **アウトカム**: 既存§0と**同一執行**＝翌営業日(T+1)寄付買い → 20営業日後の終値売り・
   往復コスト0.3%控除（`measure_base_rate` の既存関数を再利用・独自実装禁止）
6. **指標**: 帯ごとに n / **+20%到達率** / EV（コスト後平均） / 中央値 / 月数。
   比較対象= ①同一サンプルの全体平均（内部ベースライン）②既存実測ベースレート 9.5%
7. **層別しない**: 「クオリティ」は投稿に定義が無いため使わない。ROE・時価総額・業種等での
   事後層別は**禁止**（事後選択回避）。レジーム別（bull/bear）だけは記述として併記可
8. **報告義務**: 測定可能窓（開始月・終了月・月数）・銘柄×月サンプル数・200週未達で除外した数を明記

## 予言（v6型・測定前に記録）

§8-6 原則A（価格・チャート配置のみ・触媒なし）と隣接墓場（GC逆指標・`ma200_reclaim` fail・
押し目買い群 fail）から、**どの帯もベースレート9.5%近傍かそれ以下**に出る公算が高い。
例外があるとすれば「線の下（負の乖離帯）」＝割安入場側。

## 成功基準（この測定の完了条件）

- 8帯すべての n / 到達率 / EV / 中央値 が出て、`output/research/sma200w/` に保存されている
- 測定可能窓と除外数が報告に明記されている
- 結果に応じて: ベース超え帯があれば §7-* 事前登録の候補として在庫へ／無ければ指紋台帳へ
  avoidance 登録（再提案防止）

## 測定結果（2026-08-15 実施・SubAgent sma200w・成果物= output/research/sma200w/）

**測定窓**: 月末営業日 20200529〜20260630（74ヶ月・サンプルの出た月73）。開始が2020年5月なのは
bars 実データ 20160705〜（週足527週）で200週が揃う最初の月末がここだから。総サンプル **33,805**
（銘柄×月末）。除外: 200週未達 2,744（7.4%）/ T+1寄付不成立 451。20200930 は東証システム全停止で
全数落ち（AdjO 全銘柄空・既存執行定義どおり）。

| 乖離帯 | n | +20%到達率 | EV(コスト後) | 中央値 |
|---|---:|---:|---:|---:|
| < -20% | 3,723 | 6.0% | +1.62% | +0.79% |
| [-20,-10) | 2,857 | 2.9% | +0.88% | +0.66% |
| [-10,-5) | 1,848 | 2.5% | +1.11% | +0.97% |
| [-5,0) | 1,977 | 1.9% | +0.67% | +0.37% |
| [0,+5) | 2,004 | 2.2% | +0.77% | +0.67% |
| [+5,+10) | 2,119 | 2.3% | +0.44% | +0.39% |
| [+10,+20) | 3,851 | 2.2% | +0.59% | +0.58% |
| >= +20% | 15,426 | 5.1% | +0.51% | +0.14% |
| **全体（内部ベースライン）** | 33,805 | **4.0%** | +0.72% | +0.40% |

**判定=死に筋**（指紋台帳 avoidance「200週線乖離帯は+20%を濃縮しない」に登録済み）:
中央帯（-10〜+20%）は一様に約2%＝ベース4.1%を下回る。両端のみ持ち上がるU字だが、
`< -20%` は月次等重みで6.0%→5.1%へ低下し**ヒットの38.6%がコロナ後リバウンド3ヶ月に集中**、
帯シェアも 2020年28.4%→2026年5.3% と激変＝銘柄の性質でなく**相場位置**を測っている。
**予言は的中**（原則Aどおり）。ただし予言が「例外は線の下」としたのに対し、実際は
線の上端（>=+20%）も同程度に持ち上がるU字だった＝「割安入場側だけが例外」ではない。

**実装の突き合わせ**: 内部ベースライン4.0% が既存 `measure_base_rate` 全期間確定値 4.1% と一致。
samples.csv からランダム3件を別経路の独立実装で再計算し sma200w/dev/entry_date が 3/3 一致・
look-ahead なしも確認済み。

## 🔴 副産物（本測定より重大）: ベースレート「9.5%」の全期間誤用が発覚

測定担当が基準値を実読して発覚。詳細と再発防止は `tasks/lessons.md` 2026-08-15 の項が正本。
要点: 9.5% は 2026-02〜04 の**過熱3ヶ月ローカル値**で、同定義の全期間確定値は **4.1%**（catalog §6）。
`tdnet_event_profile.py` にハードコードされ、TDnet表題イベント17種の採否が2.3倍厳しい基準で
判定されていた（→ 2026-08-15 に 4.1% へ訂正・event_profile.md 再生成済み）。

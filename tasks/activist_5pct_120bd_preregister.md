## 1. 仮説（1文）
既知アクティビスト（`data/activist_dictionary.json`・時点管理付き）が新規に大量保有報告書（5%超・formCode=010000）を提出した銘柄を、提出の翌営業日寄付で買い 120営業日保有すると、同期間の TOPIX を上回る（超過リターン中央値 ≥ +2pt・勝率が無作為対照 +5pt 以上）。

## 2. 対象と期間
- 母集団: 全上場普通株（master ProdCat=011）。TOP500 制限なし（アクティビストの対象は中小型が多いため。頻度算定は §6付記III B に従い TOP500 in_universe でも併記）。
- イベント: EDINET 日次索引（`com.influx.edinet-tob` 平日 18:45 取得）の ordinanceCode=060・formCode=010000・提出者名が辞書に一致（known_since_year ≤ 提出年）・同一 filer×issuer の初回のみ。提出 15:00 以降は翌営業日を T。
- 前向き期間: 凍結日の翌営業日 〜（n≥100 到達まで）。**過去分は登録しない**（前向きのみ・過去分は §0 の記述測定として別置き）。

## 3. 判定指標（凍結）
- entry= T+1 の AdjO（look-ahead なし・T+1 がストップ高で約定不能なら翌営業日に繰延・最大3営業日＝ defer_max3bd と同じ）。
- exit= entry を1日目として 120営業日目の AdjC（time_exit）。上場廃止は廃止直前終値で打ち切り（TOB タグ付き）。損切りなし（nostop・E1 は並走記録のみ）。
- 超過= 銘柄リターン − 同期間 TOPIX。コスト= 往復 0.3% 控除（§6付記IV ③）。
- 対照= 同月の全営業日×全銘柄から無作為（seed 固定・月ブロック）。
- 副指標（記録のみ・判定に使わない）: 60営業日超過・MFE/MAE・120日内 TOB 公表の有無・提出者（辞書 id）・時価総額層（T−1 の MktCap が取れれば当時値・取れなければ静的）。

## 4. 合格基準（数値・凍結）
- 一次: **120営業日 超過リターン中央値（コスト控除後） ≥ +2.0pt（対照比）かつ 勝率 ≥ 対照 +5.0pt**、n≥100、24ヶ月以上に分散、月ブロック・ブートストラップの片側95%下限（EV v2）> 0。
- 判定保留: n<100 の間は「合格」「不合格」を言わない。**中間報告**（傾向のみ・判定でない）= 2026-12-08 と 2027-03-08。
- 頻度帯: 過去実測 219件／62か月 ≈ **3.5件／月 → スナイパー枠**（<5.6）。概算最早判定日= 登録日 + 100÷3.5 ≈ 29か月 ≈ **2029-02**（印字義務）。同時観察上限2の空きは凍結前に実測して印字する。

## 5. 撤退規律（凍結）
- n≥50 到達時点で 120日超過中央値差 ≤ 0 なら撤退（台帳に fail を残す）。
- 辞書の更新（新アクティビスト追加）は**将来の届出にのみ**適用（既登録イベントの再分類禁止）。

## 6. 分位・閾値（後から動かさない）
